# Vox Fabula Companion

Il programma che accompagna il server **Vox Fabula** di Neverwinter Nights: Enhanced Edition.

- **Voce di prossimità**: senti chi ti sta vicino in gioco, più piano man mano che si allontana.
- **Cinema e palco**: i video, i libri, i dadi e gli oggetti 3D che il server ti mostra durante la storia.

## Scaricare e installare

1. Vai su **[Releases](../../releases/latest)** e scarica `VoxFabula-Companion-Setup-<versione>.exe`.
2. Avvialo. Si installa solo per il tuo utente: non chiede la password di amministratore.
3. Apri il Companion, scrivi il tuo nome account NWN e premi **Connetti**. Poi entra nel server.

Serve Windows 10 o 11 a 64 bit.

## Aggiornamenti

Quando esce una versione nuova, il Companion te lo chiede all'avvio. Se accetti, si aggiorna da solo.
Scarica solo da questa pagina e controlla l'impronta del file prima di installarlo.

## Cosa fa sul tuo PC

- Avvia una sua copia di Mumble, separata da qualsiasi Mumble tu abbia già.
- Si collega solo ai server di Vox Fabula e, per gli aggiornamenti, a GitHub.
- Tutto quello che succede (video mostrati, file scaricati) è scritto nel registro attività, che vedi nella finestra.
- Le impostazioni stanno in `%APPDATA%\Vox Fabula Companion` e restano anche se lo disinstalli.

The companion app for the **Vox Fabula** Neverwinter Nights: Enhanced Edition server: proximity voice chat, plus the videos, books, dice and 3D objects the server shows you during the story.

Download `VoxFabula-Companion-Setup-<version>.exe` from **[Releases](../../releases/latest)**, run it (no admin rights needed), enter your NWN account name and press **Connect**. Windows 10/11 64-bit.
